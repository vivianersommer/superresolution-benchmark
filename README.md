# Image Super-Resolution with Deep Learning and Interpolation

## Context
Project to compare image super-resolution methods using Deep Learning (EDSR, ESPCN, FSRCNN, LapSRN) and classical interpolators (Bicubic, Nearest, Lanczos). The goal is to assess the quality of reconstructed images from downscaled versions using objective metrics.

## Objective
Evaluate and compare the quality of images generated by different super-resolution and interpolation methods using PSNR, SSIM, and MSE metrics.

## Methodology
- **Dataset:** Subset of COCO (100 .jpg images)
- **Preprocessing:** Images downscaled at different ratios and reconstructed by each algorithm.
- **Models:**
  - Deep Learning: EDSR, ESPCN, FSRCNN, LapSRN
  - Interpolation: Bicubic, Nearest, Lanczos
- **Metrics:**
  - PSNR (Peak Signal-to-Noise Ratio)
  - SSIM (Structural Similarity Index)
  - MSE (Mean Squared Error)

## Data Organization
- Convenience sampling (first 100 images from COCO)
- Qualitative variables: algorithm, scale, downscale factor, image name
- Quantitative variables: PSNR, SSIM, MSE for each method

## Results
- **PSNR and SSIM:** High means and low dispersion, indicating good structural preservation across all methods.
- **MSE:** High variability and presence of outliers, showing less robustness in some scenarios.
- **Highlight:** EDSR achieved the best results in PSNR, SSIM, and MSE in most cases.

### Visualizations
- Frequency tables by algorithm, scale, and downscale factor
- Boxplots and violin plots for metric distributions by algorithm
- Heatmaps with position measures (mean, mode, median, quartiles) and dispersion (standard deviation, variance, range, CV)

## Interpretation
- All algorithms maintain good structural quality.
- PSNR and SSIM are reliable metrics for comparison.
- MSE is sensitive to outliers and should be interpreted with caution.
- EDSR stands out in robustness and quality.

## Limitations
- Convenience sampling limits generalization.
- Possible bias due to image selection.
- MSE can be influenced by extreme values.

## How to Use
1. Clone the repository.
2. Install the dependencies from `requirements.txt`.
3. Generate the dataset by running `scripts/generate_dataset.py` (or use the ready file in `dataset/dataset.csv`).
4. Run `scripts/measures_position.py`, `scripts/measures_dispersion.py`, and `scripts/descriptive_analysis.py` to generate the plots.
5. Check the results in the `plots` folder.
